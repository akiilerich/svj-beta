# SVJ Beta

The test copy of SVJ, the savings tracker. Install it from **https://akiilerich.github.io/svj-beta** on the same phone as SVJ, to try new versions before they reach the main app.

- It keeps its own data and never changes SVJ's data.
- To start with your real numbers, tap **Copy my data from SVJ** (or Settings → Copy data from SVJ).
- The code lives in [akiilerich/Finance](https://github.com/akiilerich/Finance). This repository only publishes the test copy: the same `index.html` and `sw.js`, with its own name and icons.
